Hi, I'm
Sul Fahmi. S, S.Kom

Saya adalah lulusan Teknik Informatika yang memiliki minat pada pengembangan aplikasi web, sistem informasi, dan teknologi Artificial Intelligence (AI). Saat ini saya mendalami Laravel, PHP, HTML, CSS, JavaScript, dan MySQL untuk membangun aplikasi yang modern, responsif, dan efisien. Selain pengembangan web, saya juga memiliki ketertarikan pada bidang Computer Vision dan Machine Learning, khususnya implementasi YOLO untuk sistem deteksi objek dan monitoring berbasis citra. Melalui beberapa proyek yang telah saya kerjakan, saya terus mengasah kemampuan dalam pengembangan web, analisis data, pemrograman, dan penerapan teknologi AI untuk menyelesaikan permasalahan nyata.
